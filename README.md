# uniapp_Mudular

基于 uni-app 框架的多端开发项目，支持微信小程序、H5 等平台。

## 技术栈

- uni-app (Vue 3 + Vite)
- Vue.js 3

## 开发

```bash
# 安装依赖
npm install

# 运行微信小程序
npm run dev:mp-weixin

# 运行 H5
npm run dev:h5
```

## 项目结构

```
├── src/
│   ├── pages/          # 页面目录
│   ├── components/     # 组件目录
│   ├── App.vue        # 应用入口
│   ├── main.js       # 主入口
│   └── pages.json    # 路由配置
├── index.html
├── vite.config.js
└── package.json
```
